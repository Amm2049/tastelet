# TasteNet

Pick movies you love; a neural network gives you a taste persona, a favorite-genre sentence and recommendations.

AI course term project (Rangsit University). Neural collaborative filtering on MovieLens, cold-start fold-in, K-means personas.

## Quick start
_Filled in as the project is built (target: under 10 lines)._

## Architecture
React (Vite) frontend → FastAPI backend that loads a trained model artifact at startup. Training runs offline in notebooks / `ml/`.
